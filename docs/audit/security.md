애플리케이션 소스에 인증·서버 통신·민감 데이터 저장 기능은 없으며, 추적 파일의 명백한 비밀키·비밀번호 하드코딩은 발견하지 못했다. 최초 감사에서는 선택한 Android/Desktop 해석 결과와 버전 카탈로그의 Maven 고유 좌표·버전 339개에 일치 권고가 없었다. 수정 후 Android/Desktop 런타임·테스트 클래스패스를 다시 해석해 고유 좌표·버전 340개를 재조회했고 일치 권고 0개를 확인했다. 이는 모든 네이티브 바이너리·빌드 플러그인 전이 의존성이 안전하다는 판정은 아니다.

[Yarn 공식 resolutions 안내](https://classic.yarnpkg.com/lang/en/docs/selective-version-resolutions/)도 대조했다.
